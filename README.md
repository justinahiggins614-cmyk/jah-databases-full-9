# jah-databases-full-9

Shard 9 of 15 — full-record spec chunks for the **Signature Spec Catalog Pending Patents Database**
(JAH Data Bases, Project Three). Property of Justin Addam Higgins (JAH).

- `data/specs/chunks/` — full spec records as `.jsonl.gz` chunks (every field: abstract,
  patent draft, manufacture, code/demo data, AI explainer, measurements, key parameters…).
- `data/specs/chunks.json` — manifest of the chunks in this shard.

Served over GitHub Pages; the database archive page fetches chunks from here invisibly.
